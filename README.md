# Trello → Discord Morning Webhook

Simple script that posts a daily morning summary from a Trello board to a Discord channel using a webhook.

Key features:
- Fetches cards from a Trello board or a specific list
- Sends overdue, due-today, and in-progress summaries
- Optional motivational greeting generated by Google Gemini
- Supports Indonesian (`id`) and English (`en`) reminder language
- Includes a second script for review-ready card notifications

## Environment variables
Create a `.env` file (you can copy from `env.example`) and set the following values:

- `DISCORD_WEBHOOK_URL` — Discord channel webhook URL
- `TRELLO_API_KEY` — Trello API key
- `TRELLO_TOKEN` — Trello token
- `TRELLO_BOARD_ID` — Trello board ID
- `TRELLO_LIST_ID` — (optional) List ID to limit cards to a specific list
- `BOARD_TARGETS` — (optional) JSON string that maps Trello board IDs to targets (see `env.example`).
  Example value:
  ```json
  {
    "<boardIdA>": { "type": "github" },
    "<boardIdB>": { "type": "webhook", "url": "https://example.com/your-hook" }
  }
  ```
  Supported target types:
  - `github`: trigger a repository_dispatch on the configured `GITHUB_OWNER`/`GITHUB_REPO` (or override per-target with `owner`, `repo`, `token`).
  - `webhook`: forward the Trello event to the configured `url` as a POST with JSON payload.
- `GEMINI_API_KEY` — (optional) Google Gemini API key for generated greetings
- `REMINDER_LANG` — (optional) `en` or `id` (default: `id`)
- `CRON_SCHEDULE` — cron expression for schedule (default: `0 7 * * *`)
- `CRON_TIMEZONE` — timezone used by the scheduler (default: `Asia/Jakarta`)

## Install & Run

```bash
npm install
cp env.example .env
# fill .env values
npm start
```

The script runs continuously and posts according to the configured cron schedule.

## Run once (manual test)

```bash
node src/commands/index.js --now
```

## Review notification helper

Use `src/commands/checklist-review.js` to send a review-ready notification for a specific Trello card:

```bash
node src/commands/checklist-review.js <cardId>
```

This script fetches the card from Trello, generates a review message via Gemini when available, and posts it to the configured Discord webhook.

## Scheduling

Set `CRON_SCHEDULE` in `env.example` or your `.env` file. Examples:
- `0 7 * * *` — every day at 07:00
- `30 6 * * 1-5` — 06:30 on weekdays (Mon–Fri)

`CRON_TIMEZONE` defaults to `Asia/Jakarta`.

## Hosting options

Because this is a simple Node script (not a full Discord gateway bot), you can host it in several ways:

- VPS + `pm2`: `pm2 start src/commands/index.js --name trello-webhook`
- System cron: run `node src/commands/index.js --now` from crontab
- GitHub Actions scheduled workflow: run `node src/commands/index.js --now` on a schedule
- Hosting platforms such as Railway or Render

## Project files

- `src/commands/index.js` — scheduled morning report sender implementation
- `src/commands/checklist-review.js` — review-ready notification implementation
- `src/lib/trello.js` — Trello API helpers
- `src/lib/gemini.js` — Gemini prompt helpers barrel export
- `src/lib/gemini-morning.js` — Gemini morning greeting helper
- `src/lib/gemini-review.js` — Gemini review message helper
- `env.example` — sample environment variable file
- `cloudflare-worker/` — optional Cloudflare Worker integration

## Notes

- `GEMINI_API_KEY` is optional. Without it, the bot falls back to static Indonesian/English messages.
- `TRELLO_LIST_ID` is optional and limits the report to one Trello list if provided.
- The repo uses `dotenv` to load `.env`, so the file should live in the project root.
