# Trello → Discord Morning Webhook

Simple script that posts a daily morning summary from a Trello board to a Discord channel using a webhook.

Key features:
- Fetches cards from a Trello board (or a single list)
- Sends a summary of tasks due today and overdue tasks
- Optional short motivational greeting generated by Gemini (Google)
- Supports reminder language in English (`en`) or Indonesian (`id`)

## Environment variables
Create a `.env` file (you can copy from `.env.example`) and set the following values:

- `DISCORD_WEBHOOK_URL` — Discord channel webhook URL
- `TRELLO_API_KEY` — Trello API key
- `TRELLO_TOKEN` — Trello token
- `TRELLO_BOARD_ID` — Trello board ID
- `TRELLO_LIST_ID` — (optional) List ID to limit cards to a specific list
- `GEMINI_API_KEY` — (optional) Google Gemini API key for generated greetings
- `REMINDER_LANG` — (optional) `en` or `id` (default: `id`) for greeting language
- `CRON_SCHEDULE` — cron expression for schedule (default: `0 7 * * *`)
- `CRON_TIMEZONE` — timezone used by the scheduler (default: `Asia/Jakarta`)

## Install & Run

```bash
npm install
cp .env.example .env
# fill .env values
npm start
```

The script runs continuously and will post according to the configured cron schedule.

## Run once (manual test)

```bash
node index.js --now
```

## Scheduling

Set `CRON_SCHEDULE` in the `.env` file. Examples:
- `0 7 * * *` — every day at 07:00
- `30 6 * * 1-5` — 06:30 on weekdays (Mon–Fri)

`CRON_TIMEZONE` defaults to `Asia/Jakarta` (WIB). Change to your timezone if needed.

## Hosting options

Because this is a simple Node script (not a full Discord gateway bot), you can host it in several ways:

- VPS + `pm2`: `pm2 start index.js --name trello-webhook`
- Cron job: run `node index.js --now` from system crontab
- GitHub Actions scheduled workflow: run `node index.js --now` on a schedule (uses UTC)
- Hosting platforms: Railway, Render, etc. as a worker

GitHub Actions is a convenient option since it requires no server maintenance.

## GitHub Actions (optional)

You can run this project on GitHub Actions with a scheduled workflow. Add the required secrets to your repository settings (Actions → Secrets):

- `DISCORD_WEBHOOK_URL`
- `TRELLO_API_KEY`
- `TRELLO_TOKEN`
- `TRELLO_BOARD_ID`
- `TRELLO_LIST_ID` (optional)
- `GEMINI_API_KEY` (optional)

Note: GitHub Actions cron uses UTC. Adjust schedule accordingly.
